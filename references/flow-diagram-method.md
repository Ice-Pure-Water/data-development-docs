# 数据规格图的 diagram-design 执行规则

本 skill 将 [`cathrynlavery/diagram-design`](https://github.com/cathrynlavery/diagram-design) 作为流程图的规范来源。以下是生成数据规格图时必须执行的上游规则摘要；遇到细节时，以融合说明记录的上游版本对应参考文件为准。**本 skill 不另设一套流程图规范。**

唯一项目专属例外来自用户确认：连接线不画箭头，方向用移动光点表达。其余布局、节点、连线、配色、文字和动效规则均按 diagram-design。

## 选择图形类型

- 整体数据流、系统关系和数据来源到结果的架构使用 **Architecture**，按锁定版本的 [`type-architecture.md`](https://github.com/cathrynlavery/diagram-design/blob/f2f4d49ea8d632f17cf196ba26599277a93f767b/skills/diagram-design/references/type-architecture.md) 绘制。
- 只有需要展示条件、决策分支或判定结果时才用 **Flowchart**，遵循上游 `type-flowchart.md`。
- 关系或行为明显符合上游语义模式时，先加载 `semantic-patterns.md`，再按它指定的图形类型和更严格的预算执行。
- 不把 Mermaid 渲染器的自动布局当成最终图。Mermaid、流程文字和阶段读写关系只用于提取图模型；HTML 中重画 SVG。
- 本项目已确认整体流程按纵向阅读。使用 Architecture 时优先采用上到下主方向；其余情况遵循选定图形类型的布局语法。

## 上游通用设计约束

- 先从当前规格 Markdown 建立节点、关系、阶段和来源位置清单。关系须有文档依据，保留来源、配置、并行分支、汇合、结果及属性独立路径。旧 HTML 不能作为业务拓扑来源。
- 每个节点代表一个独立概念。总图以 4/10 信息密度为目标；超过 9 个节点或 12 条连线/转换时拆成总览图与细节图。最多 2 个强调色焦点、2 个注释框。拆图时总览仍展示端到端主干，细节图须与阶段说明建立明确对应。
- 按单一主方向分层；同层并行节点并排。使用固定坐标和稳定排序。依据中文标签尺寸确定节点宽高和留白，所有坐标、尺寸和间距落在 4px 网格上。
- 节点采用上游语义类型的填充和描边：来源用 `input`，配置/存储用 `store`，处理用 `backend`，核心决策或集成点用 1–2 个 `focal`，外部对象用 `external`。中文名称用易读无衬线字体；仅字段、库表、协议等技术标识使用等宽字体。遵守上游单强调色原则，不给每条来源路径各配一色。
- 连线先于节点绘制。非水平/垂直的关系用圆角正交折线，默认转角半径 8px，空间紧张时最小 6px；端口位于节点直边且与边角至少相隔 8px。线段垂直接入节点边。
- 路径不得重描、重叠或共用一段。共用同一节点边时，端口必须分开，通常间隔至少 12px。连线应避开非端点节点。确需正交线相交时，依上游 Architecture 的 bridge/hop 规则在次要路径上做跨线弧；不要把几何交叉误画成数据汇合。
- 使用上游 `style-guide.md` 中的角色色与文字层级。节点蒙版不透明，避免连线透过节点文字；图形应有 `<title>`、`<desc>`，可交互节点可键盘操作并关联页面详情。

## 用户确认的动效例外

- 连接线和路径不设置 `marker-end` 或箭头形状；动向仅由光点沿既有连线移动表示。静态连接线始终完整可见，光点不得创造新的关系或路径。
- 按上游 [`animation.md`](https://github.com/cathrynlavery/diagram-design/blob/f2f4d49ea8d632f17cf196ba26599277a93f767b/skills/diagram-design/references/animation.md) 控制动效：总图最多一个循环流动光点，循环时长至少 3 秒；动效不改变节点位置、路径、画布或语义文字。
- 光点是装饰元素，标记为 `aria-hidden="true"`、`focusable="false"`。启用 `prefers-reduced-motion: reduce` 和打印样式时停止/隐藏光点，但保留完整静态关系。
- 无 JavaScript 时图仍完整、可读。优先使用 SVG 与 CSS；动效方向应沿真实数据关系。

## 输出前核对

- 节点与连线清单完整映射到一个或多个 SVG，配置输入、来源属性路径、选举路径、汇合和最终结果均未遗漏。
- 复杂度符合上游预算；布局稳定，文字未越界；端口、路径和节点未碰撞或无依据交叉；路径未被截断或被节点遮住。
- 主流程没有箭头；动效光点沿线表示方向；减少动态效果时静态图依然能读懂。
- 核对阶段节点与阶段导航、详情及读写对象的对应关系。只核对文档表达，不验证 SQL、数据库或业务结果。
