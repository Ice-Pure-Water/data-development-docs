# 中文写作与阅读展示

## 中文表达

- 按业务上下文选自然、易懂的中文，不逐词硬译英文。术语在规格 Markdown、流程图和 HTML 中保持一致；库、表、字段、代码值、产品名和日期保留原文。
- 先说结论，再说明条件、依据、结果和例外。每段聚焦一个意思；独立判断拆开讲。来源冲突或信息不足时标明差异或“待确认”，不自行补结论。
- 首次出现的必要缩写附简短中文解释。删除套话、空泛形容词、无依据评价和重复表达。标题说明业务主题，不写 HTML 功能介绍、版本代号或内部代号。

## 信息层级与排版

- 总览层说明目标、主要数据路径和结果；讲解层说明阶段及关键判断；细节层保留条件、结果、优先级、例外和待确认事项；参考层承载库表字段、来源和 DDL 关系。
- 总览与细节使用同一事实来源，彼此对应但不整段重复。细节渐进展开，入口标题和一句摘要始终可见。
- 使用语义化标题、段落、列表、术语表和原位展开。一个标题只表达一个层级；链接文本说明实际指向。中文自然换行，不逐字断行；仅长库表名、字段名或 URL 可强制断开。
- 正文采用高对比、舒适行距和适合中文阅读的行宽。电脑端三栏详情正文保持清晰易读；图中文字按最终显示尺寸检查。不得通过缩小字号、裁切或省略号掩盖溢出，先扩宽、换行或移入详情。
- 避免卡片墙、连续色块、装饰性编号和过度强调。颜色不能单独承载含义。页面采用本地系统中文字体，不依赖远程字体或 CDN。

## 页面阅读关系

- 主图节点只放短处理名称和必要提示；业务说明放在同步的右侧详情。并行逻辑同层呈现，不堆成一段。
- 业务逻辑专题在当前页原位展开；数据对象按“作用行 × 范围列”组织，字段血缘以目标字段为阅读锚点。
- 固定导航不得遮住正文或锚点。检查实际可见字号、中文断行、技术标识溢出、焦点状态和动效降级后的可读性。
