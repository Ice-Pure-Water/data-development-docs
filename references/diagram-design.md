# 流程图规则与来源

流程图设计遵循上游 [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)。本技能锁定来源提交 `f2f4d49ea8d632f17cf196ba26599277a93f767b`（MIT）；细节以该版本的 `SKILL.md` 及架构、流程图、布局、样式和动效参考为准。本文件只规定数据规格场景的选型和适配，不另造一套绘图规范。

## 执行约定

- 画图前从当前规格 Markdown 建立节点、关系、阶段和来源位置清单。不得从旧 HTML 猜拓扑。整体数据架构使用上游 Architecture；仅表达条件判断时使用 Flowchart。必要时按上游复杂度预算拆分总览和局部图，并保持关系可追溯。
- 主流程自上而下；真实并行分支同层展示，再按事实汇合。遵循上游语义节点、布局预算、正交路由、端口间距、跨线、配色、文字和可访问性规则。先消除交叉和歧义，再加动效。
- 本技能的动效约定：连接线不带箭头；每条有向数据关系均沿真实路径显示连续流动的短线段表达方向，不得用单个光点代替。每条线保留完整静态底线；动效不得改变拓扑、节点位置或语义。减少动态效果和打印时隐藏动效，静态关系仍完整可读。
- 图与阶段导航、当前阶段详情、读写对象同步。阶段高亮使用清楚可见的背景区分，流程节点和连线维持原有语义配色，不整体灰化。
- 流程图在页面栏内完整显示，不允许内部横向拖动。中文节点文字按最终尺寸检查，扩框或换行，不得溢出。HTML 应有图标题/说明、键盘可达的节点交互及 `prefers-reduced-motion` 支持。
